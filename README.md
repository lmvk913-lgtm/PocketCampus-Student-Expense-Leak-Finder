# PocketCampus — Student Expense Leak Finder

PocketCampus is a Python command-line application designed to help college students track expenses, analyze spending patterns, manage monthly budgets, and identify potential savings.

## Features
- Record and categorize daily expenses.
- View expense records.
- Analyze monthly spending by category.
- Identify the largest spending category.
- Estimate potential savings.
- Set and monitor a monthly budget.
- Delete expenses and export records to CSV.
- Save data locally using JSON files.

## Installation and Usage
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Run the application

## Technologies
- Python
- JSON for local data storage
- CSV for expense export

## Disclaimer
PocketCampus is an educational budgeting tool. Savings estimates are illustrative and are not financial advice. Expense data is stored locally.
